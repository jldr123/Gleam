Questions

Good to know.

What exactly do I download?

A zip with the complete project: source code, tests, the App Store icon, launch screens and screenshots, and setup notes. Run npm install and npm run dev and it's up.

Can I publish it on the App Store?

Yes. Gleam runs today as an installable web app. To put it in the App Store you wrap it with Capacitor and connect Apple's in-app purchases to the existing payments module. You'll need your own Apple Developer account.

Can I rename and rebrand it?

Yes. Change the name, colours, prompts and copy as you like. The themes and prompt packs are simple data files.

Does it need a backend or database?

No. All entries are stored on the user's device, so there are no servers to pay for and no user data to protect on your side.

Do I need to be an expert developer?

Comfort with React and the command line helps. The code is cleanly organised and the setup notes walk you through running and deploying it.
